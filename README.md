# [Kôň West Official Website](https://konwest.studio)

## Usage

First install [`rumage`](https://github.com/notangelmario/rumage), if you didn't:

```console
cargo install rumage
```

Then build the site:

```console
rumage build -s source -b docs
```

This site was build using [`rumage`](https://github.com/notangelmario/rumage)
